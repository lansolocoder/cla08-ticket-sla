# 工单 SLA 与升级路由

用于本地服务工单 SLA 计时与升级路由的命令行项目。

需要 Python 3.12，无第三方依赖。在仓库根目录（或设置好 `PYTHONPATH` 的任意目录）运行：

```bash
python3 -m sla_desk --help
python3 -m sla_desk --version
python3 -m unittest discover -s tests -v
```

## 数据存储

工单数据持久化到**当前工作目录**的 SQLite 文件 `sla-desk.db`，首次写入时自动建表。所有写操作在单个数据库事务中完成，失败的命令不会留下半条记录，多次运行之间数据保持一致。

## 命令用法

### 登记工单 `register`

输入客户请求号、标题、报障人邮箱、优先级（P1/P2/P3/P4）和提交时间（ISO 8601，可带 `+08:00` 之类的偏移，也接受 `Z`）。校验通过后生成全局递增工单号 T1、T2……，状态为 `open`，提交时间按原文保存。

```bash
python3 -m sla_desk register \
  --customer-ref CR-100 \
  --title "VPN 无法连接" \
  --email alice@example.com \
  --priority P2 \
  --submitted-at 2026-09-24T09:30:00+08:00
```

输出工单号、状态和提交时间。

同一客户请求号再次登记时：

- 标题、邮箱、优先级、提交时间文本与首次**完全一致**：视为重复请求的重试，不新建工单、不改写原记录，输出原工单号并以 `0` 退出。
- 任一字段不同：报错并非零退出，不新建也不修改。

标题为空、邮箱不含 `@`、优先级不在 P1–P4、提交时间无法解析时，**一次性列明全部无效字段**并非零退出，数据库无新增也无修改。

### 查看工单 `show`

按工单号输出客户请求号、标题、报障人、优先级、提交时间和状态；工单不存在时报错并非零退出。

```bash
python3 -m sla_desk show T1
```

已合并的工单会额外输出状态 `merged`、主工单号和合并时间。

### 合并工单 `merge`

把一个工单并入另一个工单：被并入的工单状态变为 `merged`，记录主工单号与合并时间；主工单字段保持不变。合并不可逆，已合并的工单不能再作为主单或被并单参与后续合并，其客户请求号也不能再用于新建工单。

```bash
python3 -m sla_desk merge T2 T1   # T2 并入 T1
```

要求两单都存在、状态都是 `open`、且不是同一工单，否则报错并非零退出且两单状态都不变。

### 列出工单 `list`

只显示状态为 `open` 的工单，按工单号升序，每行输出工单号、优先级、标题和状态（制表符分隔）：

```bash
python3 -m sla_desk list
# T1	P2	VPN 无法连接	open
```
